# 📸 Instagram Reels Downloader Bot

A powerful Telegram bot to download Instagram Reels and extract audio.

## 🚀 Deployment

### 1. One-Click Deploy
[![Deploy](https://www.herokucdn.com/deploy/button.svg)](https://heroku.com/deploy?template=https://github.com/Ywanony/Insta)

### 2. Manual Setup
1. Clone the repo.
2. Install dependencies: `pip install -r requirements.txt`.
3. Set your environment variables.
4. Run `python main.py`.

## 🛠 Features
- Dual API Fallback (Durgesh & Hazex)
- Fast Download (Direct URL fetch)
- Audio Extraction (MP3)
- Dual Force Subscription (Direct & Request-based)
- MongoDB Integration with Caching

## ⚠️ Requirements
- FFmpeg (for audio extraction)
- MongoDB Database
- Heroku-22 Stack
